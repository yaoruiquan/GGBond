# 模型市场开发说明

- 日期：2026-11-04
- 状态：已完成（2026-11-04）
- 范围：将现有模型广场的用户展示改为模型市场；复用现有 API、鉴权与模型价格规则，不开发监控功能。

## 产品范围

模型市场按模型查询价格，展示当前分组中已接入并对访问者可见的模型。页面提供平台筛选、模型名称搜索和分组筛选，并以紧凑表格对照本站价格、官方参考价及生效倍率。同一平台和模型如果出现在多个分组，分别显示每个分组的价格行。

官方价格数据来自服务端 LiteLLM 价格目录和本地 fallback，界面称为“官方参考价”，不承诺为厂商实时官网报价。没有已接入模型时展示明确的空状态，不以价格目录中的模型伪造可用模型。

页面仅呈现查价需要的信息，不增加成功率、延迟、请求量、趋势图或其他监控指标。

## 数据与计价

- 使用 `GET /api/v1/model-plaza` 返回的可见分组及模型，不新增后端接口。
- 生效通用倍率为 `user_rate_multiplier ?? rate_multiplier`。已登录用户的专属倍率优先；匿名用户和未配置专属倍率的用户使用分组默认倍率。
- Token 模型本站价格按渠道定价乘生效倍率计算，价格以每百万 Token 展示；缓存价格和已配置的长上下文档位沿用 API 数据。
- 图片、视频模型可能启用独立倍率，必须遵循 `image_rate_independent` / `image_rate_multiplier` 与 `video_rate_independent` / `video_rate_multiplier`。按次价格保留原计费单位，不与每百万 Token 价格混算。
- 官方参考价不乘本站倍率。缺少官方目录价格时显示未提供，不推断或填入零。
- 分时价格仍沿用现有 API 模型字段；市场默认展示标准价格，并标出存在分时规则，避免把标准价格误认为所有时段均适用。

## 交互与权限

- 保留 `/model-plaza` 路径及现有设置开关和路由守卫，避免破坏已发布链接；页面标题、首页入口和导航统一使用“模型市场”。
- 平台筛选、分组筛选和搜索在前端对 API 返回的数据过滤。任一筛选条件都可清空；无匹配项与无已接入模型使用不同文案。
- 未登录提示说明登录后可能看到专属分组或个人倍率；实际可见数据仍由服务端鉴权结果决定。
- 不改管理设置字段、鉴权策略、后端模型发现范围和计价计算规则。

## 验收

- 中英文标题和导航名称一致，现有独立访问与后台内嵌访问均可用。
- 筛选、搜索、空状态有前端测试覆盖；倍率价格覆盖默认倍率、用户专属倍率及媒体独立倍率。
- `pnpm test:run`（相关测试）、`pnpm check:i18n`、`pnpm typecheck`、`pnpm lint:check` 和 `pnpm build` 通过。
- 在固定的 `4000` 端口打开页面，确认当前数据为空时展示真实空状态，不构造演示模型。
