# 配置首页联系方式

管理员可以在「系统设置 → 通用 → 站点设置 → 首页联系方式」添加文字、二维码图片或图文组合。发布后的内容对未登录访客可见。

## 添加和发布

1. 点击「添加联系方式」，填写名称，例如「客服微信」或「商务合作」。
2. 填写联系文字，或选择一张 PNG／JPEG 图片；也可以同时填写文字和上传图片。
3. 按需调整条目顺序和单项启用状态，打开「展示到首页」总开关。
4. 等待图片读取和校验完成，点击系统设置页的保存按钮。
5. 打开 Home 查看。默认首页、自定义 HTML 首页和 iframe 首页均支持展示；iframe 模式的联系方式位于外层页面、嵌入内容之后。

选择图片后先显示本地预览，只有保存成功才发布。保存失败时草稿保留，可修正后重试。关闭总开关会隐藏全部条目但保留后台配置；删除全部条目并保存会清空列表。

首页使用紧凑的联系方式入口，文字可复制，二维码默认收起。桌面端悬停或键盘聚焦入口可预览二维码，手机端点击查看；按 Escape 或点击外部可关闭。二维码保持完整比例并保留白色边距，建议上传清晰 PNG，配置完成后使用真实设备扫描确认。

## 限制

| 项目 | 限制 |
| --- | --- |
| 联系方式 | 最多 6 条，禁用项也计入 |
| 名称 | 必填，最多 40 个 Unicode 码点 |
| 文字 | 最多 500 个 Unicode 码点，按纯文本展示 |
| 图片 | PNG 或 JPEG，单张不超过 100 KiB，合计不超过 300 KiB |
| 图片尺寸 | 宽高各 64–2048 像素，总像素不超过 4,000,000 |
| 列表编码大小 | JSON 不超过 450 KiB |

每条至少提供文字或图片之一。不支持 SVG、动图、外链图片或 HTML 联系人文本；超出限制时需要重新选择图片，不会自动压缩或裁切二维码。

## 与原有客服联系方式的关系

原「客服联系方式」仍供顶部导航、个人资料和兑换页使用。首页列表单独配置，两者不会自动同步；首页列表为空时也不会自动显示旧文本。

设置保存后当前应用会刷新公共配置。其他已打开的浏览器页面需重新加载查看；多实例部署需要验证各实例缓存更新。自定义 CSP 应允许 `data:` 图片，否则二维码可能无法显示。

## 技术与运维说明

图片以 Data URL 随设置保存，无需独立上传服务或数据库迁移。管理员接口返回完整列表；公共 API 和 HTML 注入配置仅输出总开关开启后的启用项。由于图片也进入 HTML 配置，应保持二维码文件较小；更多图片资源应采用专用存储方案。
